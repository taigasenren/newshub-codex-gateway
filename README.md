# NewsHub Codex接続サーバー

NewsHubの生成AIを、本人がChatGPTで認証したCodex App Serverに接続します。OpenAI APIキーは使いません。サイトのログインとは別にCodexの認証が必要です。

## 起動

Node.js 22以上で `npm ci` を実行し、`npm start` で起動します。Codex CLIは安定版0.154.0を固定してインストールします。Dockerfileも同じバージョンを指定しています。

```
npm start
```

起動後、`data/pairing-key`に接続用コードが生成されます。このコードはOpenAI APIキーではなく、この接続サーバーへのアクセスを守るためのものです。ターミナルから本人が確認し、NewsHubの設定画面へ入力します。

1. 起動したサーバーを、管理下のHTTPSリバースプロキシで公開してください。接続先はURLのルートを使用します。SSEをバッファしない設定・180秒以上の読取タイムアウトが必要です。
2. NewsHubの「設定 → Codex接続」にHTTPSのURLと接続用コードを入力します。
3. 「ChatGPTでCodexを接続」を押します。
4. 表示されたOpenAI認証ページを開き、デバイスコードを入力してください。
5. 接続済みになると、原稿のAIアシストから生成できます。

CLIがPATHにない場合は、`NEWSHUB_CODEX_BIN`に実行ファイルの絶対パスを指定します。既存のCodex認証情報をサイトにコピーしないでください。トークンはApp Serverが自身の環境に保持します。

## 分離と接続の保護

接続サーバーは1台につき1人用です。初回に署名が検証されたNewsHub利用者のIDに固定され、他のIDからの接続を拒否します。複数人では、OSユーザーまたはコンテナと認証用ボリュームをそれぞれ分離してください。同じCodex認証や利用枠を他人に貸す構成ではありません。

NewsHubからのリクエストをHMAC、時刻、nonceで検証します。Codex RPCを直接インターネットへ公開しません。原稿処理は都度新しい作業ディレクトリを使い、書き込み禁止を設定します。シェル・ブラウザ・コンピューター操作・プラグイン・サブエージェントを無効にし、追加のツールや承認要求は受け入れません。停止ボタンと切断は実行中のturnを中断します。

ChatGPTの契約プラン・組織設定・Codex利用枠によって利用可否が変わります。ファクトチェック結果は外部情報と自動照合したものではありません。音声ファイルの自動文字起こしは、このテキスト生成連携には含まれません。

## 検証状態

サイト側の接続・認証・SSE実装とApp Serverのスキーマを照合します。利用者の実際のChatGPTログインと生成の疎通は、サーバーの配置と本人による認証後に確認してください。外部サーバーはこの配布物によって自動的には公開されません。

仕様: https://learn.chatgpt.com/docs/app-server

## 無料の外部サーバーへ設置する場合

Render Free Web Service向けの `render.yaml` を同梱しています。無料期間終了後に課金する試用プランではありません。追加料金を発生させないため、支払い方法を登録していないRenderワークスペースを使用してください。カード登録済みの場合、Freeのサーバーでも通信量やビルド時間の超過が課金される場合があります。無料枠を確保できない場合は、有料プランに変更せず設置を止めます。

1. チャットにRender連携を追加・接続します。配置前にFreeプラン・支払い方法未登録・無料枠の残量を確認します。確認できない場合は配置を進めません。
2. このディレクトリだけを配置元リポジトリのルートにします。`render.yaml` はその配置を前提としています。SitesのソースリポジトリURLをRenderから直接読めるとは限りません。
3. Free Web Service、Node.js 22、1インスタンス、`/health`、自動デプロイ無効を使用します。環境変数 `NEWSHUB_PAIRING_KEY` には32文字以上の乱数を設定します。Blueprintでは自動生成します。直接作成では、ビルドを `npm ci --omit=dev --no-audit --no-fund`、起動を `npm start` に指定します。秘密値をログ・リポジトリ・チャットに貼り付けないでください。
4. HTTPSの接続先と同じ秘密値を、Sitesの `NEWSHUB_CODEX_GATEWAY_URL` と `NEWSHUB_CODEX_GATEWAY_SECRET` に設定します。`NEWSHUB_CODEX_OWNER_EMAIL` に利用する本人のメールアドレスを指定します。
5. NewsHubの「設定 → Codex接続」で接続状態を確認し、「ChatGPTでCodexにログイン」から本人が認証します。管理側でChatGPTのパスワードやトークンをコピーする必要はありません。

Render Freeは15分未使用で休止し、再開に約1分かかります。NewsHubは接続前に最大90秒の起動待ちを行います。繰り返すのは状態確認だけで、ログインや生成を二重送信しません。休止を回避するための定期アクセスは行いません。

休止・再配置・再起動でローカルファイルとCodexの認証状態が失われるため、その都度NewsHub画面からCodexへ再ログインします。原稿や素材はSites側に保存されます。有料の永続ディスクは作成せず、30日で期限切れとなる無料PostgreSQLも使用しません。`compose.yaml` のローカル用ボリュームはRender Freeには適用しません。

無料インスタンスはワークスペース全体で月750時間です。支払い方法未登録なら、無料枠の超過時はサービスやビルドが停止します。サービス休止中や利用枠終了時はAIを利用できません。ChatGPT側の既存プランとCodex利用枠も必要です。OpenAI APIキー・API従量課金への自動切替はありません。

実際のRender配置・メモリ容量での動作・本人認証後の生成は未検証です。配置後に確認します。

公式の条件: https://render.com/docs/free
